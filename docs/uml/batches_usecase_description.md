# Вариант использования: Формирование партии

**Пользователи:** Директор, Администратор.

**Цель:** сформировать производственную партию на основе закупленного сырья, зафиксировать
выходной вес, рассчитать себестоимость и оптимальную цену реализации для последующего
управления остатками и заказами.

**Краткое описание:** Пользователь (Директор или Администратор) создаёт новую партию,
привязывая её к существующей закупке сырья. Система автоматически рассчитывает процент выхода,
себестоимость и оптимальную цену за кг. После сохранения запись фиксируется в локальной базе
данных, статус связанной закупки меняется на «В партии», а запись ставится в очередь на
синхронизацию.

**Предусловия:**
- Пользователь успешно авторизовался в системе и имеет права на добавление партий
  (роль: Директор или Администратор).
- В системе существует хотя бы одна закупка со статусом «Ожидает» (Pending).

---

## Основной сценарий

1. Пользователь переходит в раздел «Партии»;
2. Нажимает кнопку «Добавить партию»;
3. Система отображает форму ввода данных;
4. Пользователь выбирает закупку сырья из списка доступных (статус Pending);
5. Система автоматически подставляет входной вес сырья (кг) из выбранной закупки;
6. Пользователь указывает выходной вес (кг) и дату формирования партии;
7. Система автоматически рассчитывает:
   - процент выхода = (выходной вес / входной вес) × 100;
   - себестоимость = стоимость закупки + сумма расходов по закупке;
   - оптимальную цену за кг = себестоимость / выходной вес;
8. Пользователь при необходимости корректирует оптимальную цену вручную;
9. Пользователь нажимает кнопку «Сохранить»;
10. Система выполняет валидацию введённых данных;
11. Система сохраняет запись партии в локальную базу данных;
12. Система обновляет статус связанной закупки на «В партии» (IN_BATCH);
13. Запись ставится в очередь на синхронизацию;
14. Пользователю выводится сообщение об успешном формировании партии;
15. Конец.

---

## Альтернативный сценарий

1. На шаге 10, если введены некорректные данные (выходной вес превышает входной,
   отрицательные значения, не выбрана закупка, неверная дата), система выделяет
   ошибочные поля и выводит сообщение об ошибке;
2. Пользователь исправляет данные;
3. Переход на шаг 9.
