STEP 1: Data Models and Room DB
Create all entities:
1.1 Create the data/local/entity/ package and the following files:

BatchEntity.kt
PurchasedRawEntity.kt
OrderEntity.kt
ExpenseEntity.kt

Required fields:
BatchEntity (Batches)

id: String (UUID)
serverId: String?
number: String
formationDate: String (ISO 8601)
rawQuantityKg: Double
outputPercent: Int
costPrice: Double
optimalPricePerKg: Double?
status: String("ACTIVE", "SOLD_OUT")
lastModified: String
isDeleted: Boolean = false

PurchasedRawEntity

id, serverId, lastModified, isDeleted
type: String
quantityKg:Double
purchasePriceTotal: Double
pricePerKg: Double
supplierName: String
purchaseDate: String
status: String
batchId: String?

OrderEntity (Orders)

id, serverId, lastModified, isDeleted
customerName, customerPhone, customerAddress?
batchId: String
quantityKg:Double
pricePerKg: Double
totalAmount: Double
creationDate: String
shipmentDate: String?
deliveryMethod: String
status: String

ExpenseEntity (Expenses)

id, serverId, lastModified, isDeleted
type: String
amount: Double
date: String
description: String?
batchIdsJson: String (list of batch IDs in JSON)

1.2 Create AppDatabase.kt and all DAOs (BatchDao, PurchasedRawDao, OrderDao, ExpenseDao) with the following methods:

getAllNotDeleted()
getById()
insert()
update()
softDelete()

STEP 2: Repositories and UseCases
Create:

data/repository/ — repository implementations
domain/repository/ — interfaces
domain/usecase/ — UseCase for each operation (Create, Update, Delete, GetAll, etc.)

You can start with a single shared LocalRepository and then split it up.
